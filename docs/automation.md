# مسیر اصلی: تولید خودکار از سناریو

اولویت پروژه، تولید موشن از داده و کد است؛ نه توسعهٔ پنل گرافیکی دستی. رابط فعلی برای بازبینی و اصلاح موردی باقی می‌ماند. کنترل پخش، مکث، شروع مجدد و seek باید در همهٔ مراحل قابل استفاده باشد.

## مرحلهٔ فعلی — نسخهٔ ۱.۲

`سناریوی JSON → کامپایل قطعی → پروژهٔ JSON → GSAP → پیش‌نمایش`

فرمان `npm run auto` سناریوی `scenarios/demo.json` را به `projects/generated.json` تبدیل می‌کند و پیش‌نمایش همان فایل را شروع می‌کند. هیچ تنظیم دستی برای موقعیت عناصر، ورود، مکث یا خروج لازم نیست. از رابط برای پخش آزمایشی استفاده کنید.

```powershell
Set-Location C:\Motion_Automation_Hub_Ready
npm run auto
```

پورت پیش‌فرض 5500 است؛ اگر `$env:PORT` تعیین شده باشد، همان پورت استفاده می‌شود. سرور قبلی را پیش از اجرای فرمان با Ctrl+C متوقف کنید. صفحهٔ استودیو در مسیر `/apps/studio/` است. پخش خودکار مرورگر فعال نیست؛ دکمهٔ پخش را بزنید.

## ورودی ساده

```json
{
  "schemaVersion": "1.0",
  "title": "معرفی محصول",
  "scenes": [
    { "title": "ایده را بنویس", "subtitle": "تایم‌لاین خودکار ساخته می‌شود", "duration": 4 },
    { "title": "نتیجه را ببین", "duration": 3, "template": "statement" }
  ]
}
```

- فقط `schemaVersion`، عنوان پروژه و فهرست صحنه‌ها الزامی‌اند؛ هر صحنه یک `title` لازم دارد.
- ابعاد پیش‌فرض 1920×1080، زبان `fa` و FPS برابر 30 است. برای انگلیسی `language` را `en` بگذارید.
- مدت پیش‌فرض هر صحنه ۴ ثانیه است. مدت مجاز ۲ تا ۲۰ ثانیه، تعداد صحنه‌ها ۱ تا ۲۰ و مجموع مدت حداکثر ۱۲۰ ثانیه است.
- FPS سناریو عدد صحیح ۱۰ تا ۶۰ است. مدت صحنه به نزدیک‌ترین تعداد فریم گرد می‌شود؛ زمان‌بندی ورود/خروج نیز بر اساس فریم ساخته می‌شود. FPS فعلاً مبنای محاسبه است؛ نرخ نمایش مرورگر را قفل نمی‌کند.
- قالب `title-card` دایرهٔ رنگی، عنوان و زیرعنوان اختیاری دارد. قالب `statement` فقط متن دارد. قالب پیش‌فرض `title-card` است.
- هر عنصر ورود، یک بازهٔ نمایش ثابت و خروج مستقل دارد؛ صحنه‌ها پشت‌سرهم‌اند و در مرز بین آن‌ها عناصر پنهان می‌شوند. گذار هم‌پوشان فعلاً نداریم.
- رنگ‌های `background`، `accent` و `textColor` اختیاری و به صورت `#RRGGBB` هستند. پس‌زمینه در کل پروژه ثابت است.
- عنوان صحنه حداکثر ۸۰ و زیرعنوان حداکثر ۱۶۰ کاراکتر است. چیدمان بلند، قلم اختصاصی و قالب‌های پیچیده در این مرحله وجود ندارند؛ متن‌ها را کوتاه نگه دارید و خروجی را با کنترل پخش بازبینی کنید.

قرارداد کامل: `packages/scenario-engine/scenario.schema.json`. فیلد ناشناخته و کد اجرایی پذیرفته نمی‌شود. این مسیر سناریو AI داخلی ندارد؛ مسیر مستقل دریافت کد از بیرون و رندر در راهنمای rendering.md آمده است.

## فایل و فرمان اختصاصی

```powershell
Set-Location C:\Motion_Automation_Hub_Ready
npm run generate -- --input scenarios/demo.json --output projects/my-motion.json
if ($LASTEXITCODE -ne 0) { throw "Generation failed" }
node server/index.js --project projects/my-motion.json
```

برای آزمایش بدون اجرای سرور فقط `npm run generate` را بزنید. برای مشاهدهٔ خروجی موجود بدون تولید دوباره `npm run preview:generated` را بزنید. `npm start` همچنان پروژهٔ دستی قبلی (`projects/demo.json`) را باز می‌کند. نام فایل فعال در پنل نشان داده می‌شود؛ API ذخیره نیز روی همان فایل فعال کار می‌کند.

## تکرارپذیری و نگهداری فایل‌ها

ورودی یکسان، خروجی JSON یکسان می‌دهد؛ شناسه‌ها ثابت‌اند و زمان تصادفی، اتصال شبکه یا اجرای کد ورودی وجود ندارد. اگر خروجی یکسان باشد، دوباره نوشته نمی‌شود. پیش از تغییر خروجی موجود، نسخهٔ قبلی در `.generation-backups` کنار فایل خروجی ذخیره می‌شود. در صورت سناریوی نامعتبر، فایل قبلی دست‌نخورده می‌ماند. اگر خروجی موجود خراب یا ناسازگار باشد، مولد آن را بازنویسی نمی‌کند؛ ابتدا آن را کنار بگذارید یا مسیر خروجی جدید بدهید.

`projects/demo.json` تغییر نمی‌کند. `projects/generated.json` و پشتیبان‌ها خارج از Git هستند. فایل‌های خروجی اختصاصی خود را جداگانه نگهداری کنید. پیش از تولید دوباره، سرور همان فایل را متوقف کنید. سناریو منبع اصلی است؛ اصلاح دستی پروژهٔ تولیدشده در تولید بعدی جایگزین و پشتیبان‌گیری می‌شود. تغییرات پایدار را در سناریو اعمال کنید.

فونت فعلی از سیستم تأمین می‌شود؛ برابری پیکسلی فقط در مرورگر و محیط یکسان بررسی شده، نه بین همهٔ دستگاه‌ها. رندر قطعی ویدئو و فونت ثابت در مرحلهٔ بعد بررسی خواهند شد.

## بررسی

`npm test` شامل قرارداد سناریو، تولید چندصحنه‌ای، FPS و مدت کسری، ورودی نامعتبر، تکرارپذیری و پشتیبان است.

`npm run test:browser` علاوه بر تست‌های قبلی، فریم ورود/نمایش/خروج، پنهان‌شدن صحنه‌ها در مرز، پخش بین صحنه‌ها و برابری پیکسلی پس از seek رفت‌وبرگشتی را روی خروجی خودکار بررسی می‌کند. سرورها و فایل‌های آزمون موقت‌اند؛ پروژهٔ کاربر تغییر نمی‌کند. تصویر هر صحنه در `test-results/automatic-scene-1.png` تا `automatic-scene-3.png` تولید می‌شود.

رندر معمولی Playwright و FFmpeg در نسخهٔ ۱.۳ اضافه شده است؛ راهنمای rendering.md را بخوانید. طبق تصمیم جدید کاربر، کد موشن توسط مدل رسمی AI خارج از سرور تولید و تزریق می‌شود. اتصال مدل و اتوماسیون محلی هنوز خارج از این مرحله‌اند. media-mcp مستقل می‌ماند.
