# نسخهٔ ۱.۴ — ورودی کد و مقایسهٔ سه سبک

در این مرحله کتابخانهٔ جدید یا موتور React اضافه نشده است. یک سناریوی مشترک با GSAP و قابلیت‌های بومی HTML/CSS/SVG در سه بیان ساخته می‌شود:

| سبک | تصمیم بصری و حرکت |
|---|---|
| مینیمال | زمینهٔ روشن، تایپوگرافی غالب، فضای خالی و حرکت کوتاه و آرام |
| محصول مدرن | زمینهٔ تیره، نور رنگی، کارت‌های فرایند و ورود فشرده‌تر |
| آموزشی | کاغذ خط‌دار، خطوط SVG دست‌کشیدهٔ ثابت و تأکیدهای یادداشتی |

این‌ها نمونه‌های اولیهٔ طراحی برای ارزیابی انسانی‌اند؛ «سلیقهٔ خودکار» یا تضمین کیفیت حرفه‌ای برای هر محتوا ادعا نمی‌شود. سبک آموزشی از Rough.js استفاده نمی‌کند. متن فارسی به حروف مستقل شکسته نشده است.

## دریافت و اجرای پنل

سرور قبلی را با Ctrl+C متوقف کنید:

```powershell
Set-Location C:\Motion_Automation_Hub_Ready
git pull --ff-only origin motion-studio-base
if ($LASTEXITCODE -ne 0) { throw 'Update failed' }
npm ci
if ($LASTEXITCODE -ne 0) { throw 'Install failed' }
npm start
```

از استودیوی قبلی روی «ورود کد و ساخت MP4» بزنید؛ یا `http://127.0.0.1:5500/code-preview/` را باز کنید. اگر PORT دیگری دارید همان را جایگزین کنید. مرورگر را با Ctrl+F5 تازه کنید.

۱. نمونهٔ دلخواه را انتخاب و «بارگذاری نمونه» را بزنید؛ پیش از جایگزینی کد فعلی تأیید گرفته می‌شود.
۲. کد در کادر قابل ویرایش است. می‌توانید آن را کامل با کد دریافت‌شده از مدل جایگزین کنید.
۳. «اجرای پیش‌نمایش کد» کد کادر را اجرا می‌کند؛ پخش، مکث، شروع مجدد و seek حفظ شده‌اند.
۴. «ساخت MP4 از همین کد» دقیقاً متن فعلی کادر را به API می‌فرستد؛ نیازی به ذخیره یا جایگزینی motion/reel.js نیست.
۵. پیشرفت و خطا در پنل نمایش داده می‌شود و پس از موفقیت لینک دریافت MP4 ظاهر می‌شود. نسخهٔ اصلی ویدئو در outputs سرور باقی می‌ماند. تغییر کد، لینک خروجی قبلی را پنهان می‌کند تا با نسخهٔ جدید اشتباه نشود.

کد ورودی باید قرارداد ES module با composition و createMotion را رعایت کند؛ JSX/TSX، خروجی تصویری Canva یا یک سند HTML کامل در این کادر مستقیم اجرا نمی‌شوند. کد مورداعتماد در همان مرورگر پیش‌نمایش اجرا می‌شود؛ پنل sandbox امنیتی برای کد ناشناس نیست. قرارداد و پیش‌نیازهای Chrome/Edge و FFmpeg در [راهنمای رندر](rendering.md) آمده است.

## تولید هر سه ویدئو با یک فرمان

```powershell
Set-Location C:\Motion_Automation_Hub_Ready
npm run render:styles
```

سه MP4 با نام‌های minimal، product و educational به‌همراه کد مستقل هر کدام در پوشهٔ یکتای `outputs/style-study-...` تولید می‌شوند. هر نمونه عمودی 1080×1920، شش‌ثانیه‌ای و ۳۰ FPS با دو صحنه است. مسیر پوشه در پایان چاپ می‌شود. Chromium جدا لازم نیست اگر Chrome یا Edge شناسایی شود؛ FFmpeg همچنان لازم است.

منبع متن مشترک `scenarios/style-study.json` است. فایل نمونهٔ قدیمی و ویدئوهای قبلی بازنویسی نمی‌شوند. این مرحله orchestration خارجی، اتصال AI یا واردکردن خودکار طرح Canva ندارد.

## بررسی و انتخاب انسانی

هر سه نمونه با متن و مدت یکسان ساخته می‌شوند. هنگام مقایسه این‌ها را بررسی کنید: تناسب حس با پیام، خوانایی روی موبایل، فرصت خواندن متن، میزان شلوغی و ریتم ورود/خروج. اگر هیچ‌کدام مناسب نبود، قواعد بصری را اصلاح می‌کنیم؛ صرف افزودن افکت یا کتابخانه انتخاب بعدی نیست.

تست‌ها:

```powershell
npm test
npm run test:panel
npm run test:browser
npm run test:render
```

آزمون پنل از ورودی واقعی textarea، پیش‌نمایش و پخش، دریافت نمونه‌ها، ارسال کد و دریافت MP4 استفاده می‌کند. تست‌ها فایل‌های پروژهٔ کاربر را تغییر نمی‌دهند. تصاویر بررسی سبک‌ها در `test-results/style-minimal.png`، `style-product.png` و `style-educational.png` ذخیره می‌شوند. هر سه ویدئوی کامل در محیط این جلسه رندر و با ffprobe از نظر ابعاد، ۱۸۰ فریم و مدت ۶ ثانیه بررسی شده‌اند؛ تأیید زیبایی‌شناختی نهایی با کاربر است.
